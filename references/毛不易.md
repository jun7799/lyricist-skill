# 毛不易（maobuyi）：平凡烟火的白描词人

## 风格画像

护士出身、《明日之子》冠军，华语乐坛少有的**完全为平凡人写词**的创作者。他的词不仰望也不控诉，就是安安静静把日子里的物件（小方桌、一荤一素、月儿风儿）摆出来，深情全部藏在白描里——写母亲去世，通篇不提一个"想"字，只说"月儿明 风儿轻 可是你在敲打我的窗棂"。自嘲时也不狠，像喝多了的老实人红着脸说真话（"像我这样优秀的人 本该灿烂过一生"）。

**核心技法**：
1. **生活物件承载深情**：感情不说破，落在具体物件上 → "一张小方桌 有一荤一素"
2. **敬酒排比结构**：一杯敬X 一杯敬Y，一杯一杯把人生敬完 → "一杯敬朝阳 一杯敬月光"
3. **自嘲式自白**：用"优秀/聪明"的反话写平凡 → "像我这样优秀的人 本该灿烂过一生"
4. **克制抒情**：情绪顶点也不喊，往回收 → 思念写成"你在敲打我的窗棂"
5. **童谣式柔韵**：叠词+柔韵制造摇篮曲质地 → "月儿明 风儿轻"
6. **动词名词化**：形容词当动词用的诗感 → "温柔了寒窗"、"厚重了肩膀"

**语言质地**：全白话、句子短、烟火气；青年视角（20-30岁）；安静克制，听感像深夜电台。

---

## 子风格

### 1. 烟火白描（yanhuo_baimiao）
- **代表作**：《一荤一素》《平凡的一天》《南一道街》
- **特征**：日常生活的诗意打捞，一碗饭、一条街、一天的光阴。适合亲情、乡愁、日常治愈主题
- **句式基调**：物件白描 + 童谣柔韵

### 2. 自嘲敬酒（zichao_jingjiu）
- **代表作**：《消愁》《像我这样的人》《感觉自己是巨星》
- **特征**：平凡人的自白书，自嘲里带体温，苦涩里带幽默。适合迷茫、北漂、深夜emo主题
- **句式基调**：一杯敬排比 + 像我这样自白

## 核心意象词库

- **烟火系**：小方桌、一荤一素、日出日落、灶台、热汤、巷子、路灯、窗棂、缝补、晾晒
- **敬酒系**：朝阳、月光、故乡、远方、明天、过往、自由、死亡、清醒、荒唐
- **平凡系**：人海、浮沉、碌碌无为、庸常、出租屋、车票、行李、工牌、地铁末班车
- **柔韵系**：月儿明、风儿轻、摇椅、蒲扇、童谣、晚安、旧梦
- **时间系**：二十多年、一生、又一天、四季、来来往往

## 经典句式模板

1. `[时间循环]+[空间纵深]，[一张/一件]+[具体到极致的物件]+[它的全部内容]`
   → "日出又日落 深处再深处 一张小方桌 有一荤一素"《一荤一素》
2. `一杯敬+[宏大名词]，一杯敬+[对应名词]，[动词]+我的+[向往/命运]`
   → "一杯敬朝阳 一杯敬月光 唤醒我的向往 温柔了寒窗"《消愁》
3. `一杯敬+[时间]，一杯敬+[时间]，[支撑/厚重]+我的+[身体部位/成长]`
   → "一杯敬明天 一杯敬过往 支撑我的身体 厚重了肩膀"《消愁》
4. `像我这样+[正面形容词]的人，本该+[灿烂的人生]，怎么+[平凡的现状]`
   → "像我这样优秀的人 本该灿烂过一生 怎么二十多年到头来 还在人海里浮沉"《像我这样的人》
5. `太+[年轻]的人，他总是+[不满足/不懂事]，固执地+[远行/错过]`
   → "太年轻的人 他总是不满足 固执地不愿停下 远行的脚步"《一荤一素》
6. `[童谣式叠韵短句]，可是你+[在细微处回来]`
   → "月儿明 风儿轻 可是你在敲打我的窗棂"《一荤一素》
7. `人生+[苦短/无常]，何必+[执念]`
   → "人生苦短 何必念念不忘"《消愁》

## 韵脚偏好

- **敬酒系 -ang**（光/窗/膀/往/场/方）——开阔又怅然的韵，排比敬酒的主力韵
- **白描系 -in/-ing/-i**（轻/棂/行/里/去）——摇篮曲式的柔韵
- 自白系可用 -en/-eng（人/生/沉/们）
- 韵脚疏朗，两三句一韵，不密集轰炸——留出口语的松弛感

## 结构与语言特征

- 主歌是**物件和场景的白描**（越具体越好：小方桌、一荤一素、月儿风儿）
- 副歌是**排比升华**（敬酒排比/像我这样排比），句式整齐
- 句子短（4-9字为主），断句口语化
- 情绪**永远往回收**——最深情的地方音量最小
- 结尾常落回日常（一顿饭、一句晚安、一盏灯）

## 与其他词人的区分点

- vs **李宗盛**：同是白话，李宗盛是**中年回望的溃败与和解**（"越过山丘 才发现无人等候"，认了）；毛不易是**青年当下的平凡与自足**（"一张小方桌 有一荤一素"，守着）。李宗盛叹气，毛不易晚安
- vs **高晓松**：高晓松的诗意**脱离烟火**（白雪、山岗、白衣飘飘）；毛不易的诗意**全部来自烟火**（小方桌、热汤、路灯）。写毛不易时不要出现"远方、流浪、山岗"
- vs **林夕**：同写孤独，林夕是**内省追问**（向内挖哲学）；毛不易是**向外白描**（向外看生活，孤独藏在物件里）
- vs **唐恬**：毛不易**向内自愈**（我的浮沉我的杯）；唐恬**向外立像**（给无名英雄造像）
- **自检**：写完检查——每个抽象情绪是否都有具体物件接着？没有的话就补上；删掉一切"华丽的形容词"

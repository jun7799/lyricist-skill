# 黄伟文（huangweiwen）：毒舌戏剧化的暗黑怪才

## 风格画像

与林夕并称香港词坛"两个伟文"（黄伟文 Wyman / 梁伟文=林夕），时尚 icon，写词角度刁钻毒辣。林夕负责"美丽的遗憾"，黄伟文负责"丑陋的真实"——自卑、嫉妒、不甘、虚荣这些别人不敢碰的负面情绪，他敢写到极致，最后给一个**苦涩的自洽**。整首词常像一出独幕剧：有人物、有场景、有戏剧性独白。

**核心技法**：
1. **戏剧独白体**：歌词是小人物独白，有具体场景和事件 → "那年十八 母校舞会 站着如喽啰"
2. **反讽悖论**：用自夸写自卑，用夸张写恐惧 → "你当我是浮夸吧 夸张只因我很怕"
3. **修炼比喻**：借酿葡萄酒/吃苦瓜这类"过程性苦涩"写人生成长 → "应该怎么爱 可惜书里从没记载"
4. **骄傲的代价**：女性角色宁可孤傲也不将就 → "情愿获得你的尊敬 承受太高傲的罪名"
5. **短句顿挫**：戏剧感的节奏靠短句切断，情绪在顿挫里蓄力

**语言质地**：口语+毒舌，白话里藏刀；戏剧张力强；题材刁钻（写鞋、写胖、写自卑、写过气）。

## 子风格

### 1. 毒舌自嘲（dushu_zichao）
- **代表作**：《浮夸》《打回原形》《垃圾》
- **特征**：小人物被忽视到极致后的爆发式自白。表面张牙舞爪，内里是"求你看见我"。适合小人物、职场憋屈、存在感焦虑主题
- **句式基调**：反讽宣言 + 含泪发誓

### 2. 哲理修炼（zheli_xiulian）
- **代表作**：《葡萄成熟时》《苦瓜》《年度之歌》
- **特征**：把人生挫败写成必修课——伤要够重，果才够甜。苦涩但自立的智慧，适合失恋成长、事业挫折主题
- **句式基调**：修炼比喻 + 苦涩自洽

### 3. 女性心史（nvxing_xinshi）
- **代表作**：《野孩子》《可惜我是水瓶座》《勇》《下一站天后》
- **特征**：清醒、骄傲、不将就的女性视角。宁可孤单也不折断翅膀。适合女性向情感、独立主题
- **句式基调**：宁愿句式 + 罪名/代价

## 核心意象词库

- **独白系**：舞会、喽啰、配角、观众、舞台、灯光、注视、掌声、面具
- **修炼系**：葡萄、酿、果园、春天、花开、结果、伤口、白头、苦、陈年
- **女性系**：虚荣、罪名、高傲、尊敬、仙境、蜜月套房、翅膀、皇冠
- **暗黑系**：浮华、夜、镜子、原形、怪物、废墟、裂缝
- **时间系**：那年十八、一夜、岁月、年度、过气、流行

## 经典句式模板

1. `[当年被忽视的场景]，[含泪发誓式宣言]`
   → "那年十八 母校舞会 站着如喽啰 / 那时候我含泪发誓各位必须看到我"《浮夸》
2. `你当我+[自贬标签]吧，[夸张行为]只因我很怕+[真实的恐惧]`
   → "你当我是浮夸吧 夸张只因我很怕 / 似木头 似石头的话 会被注意吗"《浮夸》
3. `应该怎么+[人生课题]，可惜书里从没记载；终于摸出来，但[岁月/时机]却不回来`
   → "应该怎么爱 可惜书里从没记载 / 终于摸出来 但岁月却不回来"《葡萄成熟时》
4. `别让+[软肋情绪]害你+[惨烈后果]，[赢得的]+[苦涩的东西]`
   → "别让 寂寞害你想得一夜白头 / 赢得不需要的自由 和最耀眼伤口"《葡萄成熟时》
5. `就算+[将就的选项]，除外都是+[虚荣/不甘]`
   → "就算只谈一场感情 除外都是一时虚荣"《野孩子》
6. `情愿+[骄傲的选择]，承受+[世俗的罪名]`
   → "情愿获得你的尊敬 承受太高傲的罪名"《野孩子》
7. `如果我也+[平凡 普通]，你[会否/凭什么]+[看见我/选择我]`（打回原形式的不安叩问）

## 韵脚偏好

- 粤语作品按粤韵（-oeng/-au/-oi），戏剧张力靠韵脚的顿挫感
- 国语可用 -ao（怕/吧/大/发）、-ou（头/口/手/守）
- **特色**：副歌宣言句常用短促韵脚连击，模拟"喊出来"的效果
- 段落间可换韵，配合戏剧场景切换

## 结构与语言特征

- 开场是**场景白描**（像剧本第一幕：那年十八/舞会）
- 主歌递进倾诉，情绪逐层加码
- 副歌是**宣言式爆发**（短句+反讽+叩问）
- 结尾常见**苦涩自洽**——不求圆满，但求一个说得通的自我交代
- 大量第一人称独白，常有隐形的"你"作为倾诉对象

## 与其他词人的区分点

- vs **林夕**：林夕的痛最终**放下**（哲学出口，体面轻声）；黄伟文的痛最终**不甘或自洽**（戏剧出口，带血带泪）。写黄伟文切忌太早释然——他的主人公到最后一刻都攥着拳头
- vs **李宗盛**：黄伟文的戏剧化是"**演给你看**"（舞台感、夸张、反讽）；李宗盛是"**坐下来唠**"（零表演性、大白话）。一句"你看我多惨"如果带表演性质是黄伟文，平铺直叙的是李宗盛
- vs **唐恬**：黄伟文写暗夜里的**自卑与反击**，唐恬写暗夜里的**尊严与坚守**——同样不被看见，黄伟文质问"你们为什么不看我"，唐恬回答"不需要光我也算英雄"
- **自检**：副歌金句如果是"想通的道理"→那是林夕；是"扎人的反话"→才是黄伟文

# 李宗盛（lizongsheng）：中年叙事的大白话人生词人

## 风格画像

滚石教父，写尽都市男女的求不得与放不下。他的词几乎是**零修辞**——不堆意象、不玩通感，就是把话说到位，像深夜和一个老友对坐唠嗑，但每一句都砸在人生痛点上。年轻时写别人的情伤（《爱的代价》《阴天》），60岁后写自己的半生（《山丘》《给自己的歌》，后者获金曲奖最佳作词）。他的杀伤力来自**时间感**——歌词里有十年二十年的跨度，年轻人写不出来。

**核心技法**：
1. **大白话直击**：最平的字，最狠的话 → "想得却不可得 你奈人生何"
2. **时间跨度叙事**：从青年写到中年，一句词压半生 → "越过山丘 才发现无人等候"
3. **自嘲式和解**：不控诉命运，先嘲笑自己 → "还未如愿见着不朽 就把自己先搞丢"
4. **朴素到扎心的细节**：不写"孤独"，写"记不得上一次是谁给的拥抱 在什么时候"
5. **说话式韵脚**：押韵松弛，跟语感走，绝不因韵害意
6. **劝世收尾**：像长辈的口气，话糙理端 → "走吧走吧 人总要学着自己长大"

**语言质地**：全口语、唠嗑体、句子参差如说话；书面词几乎绝迹；适合35+视角的回望题材。

## 子风格

### 1. 人生回望（rensheng_huiwang）
- **代表作**：《山丘》《给自己的歌》《新写的旧歌》
- **特征**：中年自白，检点半生的遗憾、贪念与不甘，最后和自己握手言和。适合人生阶段总结、中年心境、和解主题
- **句式基调**：越过/才发现 + 奈人生何

### 2. 凡人白描（fanren_baimiao）
- **代表作**：《凡人歌》《我是一只小小鸟》《寂寞难耐》
- **特征**：市井众生的生存状态速写，自嘲中带温情。适合打工人、生活压力、平凡挣扎主题
- **句式基调**：你我皆凡人式共情宣言

### 3. 情路沧桑（qinglu_cangsang）
- **代表作**：《阴天》《爱的代价》《为你我受冷风吹》
- **特征**：感情复盘的大白话，没有怨只有懂。适合失恋成长、多年后回看一段感情主题
- **句式基调**：走吧走吧式劝世 + 沉淀式自省

## 经典句式模板

1. `想得却不可得，你奈人生何`
   → 想要/得不到/无奈反问三连，人生课题的标准句式《给自己的歌》
2. `越过+[人生阶段/目标]，才发现+[迟来的真相]`
   → "越过山丘 才发现无人等候"《山丘》
3. `还未+[心愿]，就先把自己+[搞丢/弄丢]`
   → "还未如愿见着不朽 就把自己先搞丢"《山丘》
4. `为何记不得+[最朴素的事]，在什么时候`
   → "为何记不得上一次是谁给的拥抱 在什么时候"《山丘》
5. `你我皆+[凡人/普通人]，+[生存状态的直白罗列]`
   → "你我皆凡人 生在人世间 终日奔波苦 一刻不得闲"《凡人歌》
6. `走吧走吧，人总要+[必须自己完成的事]`
   → "走吧走吧 人总要学着自己长大"《爱的代价》
7. `该舍的舍不得，只顾着跟往事瞎扯`
   → 舍与不舍的拉锯，用"瞎扯"这类口语词收《给自己的歌》
8. `[天气/环境]的直白陈述，当所有[思绪]都一点一点沉淀`
   → "阴天 在不开灯的房间 当所有思绪都一点一点沉淀"《阴天》

## 韵脚偏好

- **韵脚松弛**是李宗盛的标志——押韵服从说话的呼吸感，允许跳韵
- 常用：-e/-uo（何/扯/舍/说）、-ou（候/头/丢/守）、-an（闲/间/烦/淡）
- 副歌结论句常落开口韵（-an/-ang）显得坦荡
- **切忌**：不要为了韵脚把口语换成书面词——那就不像他了

## 结构与语言特征

- 开场常是**回忆触发**（一件小事/一个阴天/一段旋律把往事勾出来）
- 主歌是叙事唠嗑，时间线推进（那时→后来→如今）
- 副歌是**人生结论**——大白话金句，像叹一口气之后的明白
- 桥段常见**自嘲**，冲淡伤感
- 结尾**无奈但平静**——不解决问题，但接受了
- 大量使用语气词和口头语（"呢"、"吧"、"算了吧"）

## 与其他词人的区分点

- vs **黄伟文**：黄伟文的惨是"**演给你看**"（戏剧舞台感），李宗盛的惨是"**说给自己听**"（零表演性）。写李宗盛时删掉一切夸张修辞和感叹号
- vs **毛不易**：同是白话，李宗盛是**中年回望的溃败与和解**（山丘无人等候），毛不易是**青年当下的平凡与自足**（一荤一素的小方桌）。视角年龄差二十岁
- vs **罗大佑**：李宗盛的白话是**纯唠嗑**（只管一地鸡毛），罗大佑的白话**有文言骨架和家国格局**（个人的事连着时代）
- **自检**：写完后读一遍——如果哪句话"文绉绉"了就删掉重写成说话；如果一句话能想象成酒桌上的开场白，就对了

**lyricist** 是一个 Claude Code Skill：你说一个主题、一点感觉，它在九位华语顶级作词人中自动挑出最对的那一位，按**他（她）自己的意象、句式、韵脚**来写词，最后直出 Suno 风格素材（英文风格标签 + BPM 建议），可直接衔接 [suno](https://suno.com) 生成歌曲。

## 怎么用

```
你：写一首失恋的歌词，要那种看开了、放下了的感觉

引擎：命中 林夕 · 禅意放下
      （释然向失恋是林夕的招牌领域）

《路过就够》
    谁能把风 收进袖口
    谁能要彩虹 为谁停留
    你从我的雨季 路过之后
    天空放晴 就已经足够

Suno风格标签：mandopop ballad, emotional, piano, strings, female vocals
建议BPM：68
```

三种触发方式：

1. **只给主题**：「写首毕业歌」→ 自动匹配（毕业 → 阿信·青春告别）
2. **给倾向**：「写失恋，但想反击那种」→ 命中黄伟文·毒舌自嘲
3. **点名词人**：「用林夕的感觉写」「像毛不易那样」→ 直达对应风格档案

## 示例作品（examples/ 目录）

| 作品 | 词人 | 触发方式 |
|------|------|---------|
| 《路过就够》 | 林夕 · 禅意放下 | 主题 + 倾向（失恋要释然） |
| 《秋霜染砚》 | 方文山 · 中国风 | 主题 + 风格（秋夜思念 / 中国风） |
| 《同学会》 | 李宗盛 · 人生回望 | 主题 + 人生阶段（同学会 / 中年） |

三首放在一起能直观感受「匹配词人」到底改变了什么：林夕的哲学释然、方文山的古典意象、李宗盛的零修辞唠嗑——同一个人（AI）写的，三种完全不同的质地。

## 它是怎么工作的

```
你的主题 + 倾向
   ↓ 两级匹配（关键词层 → 情绪层 → 主题层；歧义时询问一次）
词人 + 子风格
   ↓ 加载该词人的风格档案（references 目录下对应词人的文件）
按档案创作：意象词库选意象 → 句式骨架搭建 → 韵脚偏好落韵
   ↓ 风格校验（对照"区分点"清单，防止写成通用歌词）
完整歌词 + Suno素材 + 创作说明
   ↓ （可选）
suno 生成流程 → MP3
```

每份词人档案包含：**风格画像 / 子风格 / 核心意象词库 / 经典句式模板（配真实例句）/ 韵脚偏好 / 结构与语言特征 / 与其他词人的区分点 / Suno曲风标签 / 参考金句**。

## 安装

```bash
git clone https://github.com/jun7799/lyricist-skill.git

# 把整个文件夹放进 Claude Code 的 skills 目录
# Windows:   C:\Users\<你>\.claude\skills\lyricist-skill
# macOS/Linux: ~/.claude/skills/lyricist-skill
```

装好后在 Claude Code 里说「写首歌词」即可自动触发。

## 设计细节（为什么它不像"通用AI作词"）

- **硬性区分点机制**：每份档案强制写明与其他词人的差异。同样是失恋——林夕的出口是哲学（放下），黄伟文的出口是反击（不甘），李宗盛的出口是和解（认了），毛不易的出口是晚安（往回收）。写完对照自检，防止千人一面
- **金句联网验证**：建库时对 18 首代表作金句逐一联网核对原文，纠正了两处广为流传的误传：「宜静不是嫁给了大雄」出自《错错错》而非《干杯》；《野孩子》里并没有「我不介意孤独」这句
- **反AI八股条款**：创作铁律明令禁止「岁月的长河」「时光的画卷」式空洞套话，每个意象必须具体可感，副歌必须有能被单独记住的金句
- **两级匹配 + 最少打扰**：能自动匹配的自动匹配并说明理由，拿不准才询问，只问一次

## 来历

这个 skill 由「文山 skill」（方文山单人版，含 90+ 首歌词全文语料的风格分析）升级而来——单人引擎跑通方法论后，把同一套「意象库 + 句式骨架 + 韵脚偏好 + 区分点」的建档方法复制到九位词人，并加入匹配引擎。
